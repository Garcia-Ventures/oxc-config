# Security Policy

## Supported Versions

The `main` branch (latest published `@gv-tech/oxc-config` version) is the only currently supported version.

## Reporting a Vulnerability

Please send all security findings to [security@gventureshq.com](mailto:security@gventureshq.com). Include all relevant information pertaining to the vulnerability, including where / how it was found, and what repository or dependencies are affected.
